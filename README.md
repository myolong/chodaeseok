# 초대석

인터뷰형 유튜브·팟캐스트 채널과 출연하고 싶은 작가·대표·강사를 잇는 게스트 매칭 사이트 (4주 시험판).

- 화면: `public/` (외부 라이브러리 없음, 주소 뒤 `#/...` 로 화면 전환)
- 서버: `src/worker.js` (Cloudflare Workers + Durable Object SQLite 하나에 모든 자료 저장)
- 채널 지도 초기 목록: `src/channels.json` (2026-11-26 유튜브 공개 정보로 확인한 37곳, 연락처는 모으지 않음)
- 숫자 화면: `/stats` (게스트·가입 채널·제안·출연 수, 삭제 요청·신고 목록)

## 지키는 선
- 초대석은 수수료를 받지 않고 연결만 함(출연 조건은 당사자끼리, 유료 광고면 표시 안내). 연기·예능 캐스팅, 세무·회계 분야 게스트는 받지 않음
- 연락처는 제안이 수락된 상대에게만 보임
- 채널에 광고·섭외 메일을 보내지 않음, 목록에서 빼기 요청은 즉시 반영

## 배포
main 에 올리면 Cloudflare Workers Builds 가 `npx wrangler deploy` 로 배포.
